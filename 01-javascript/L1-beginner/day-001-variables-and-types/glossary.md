# Glossary: Day 1

- **Binding**: the link between a name and a value.
- **Block scope**: a variable lives only inside the nearest `{ }`.
- **Coercion**: automatic conversion between types.
- **Falsy**: a value that becomes `false` in a boolean context.
- **Hoisting**: declarations are processed before code runs.
- **Primitive**: an immutable, non-object value.
- **Reference type**: a value stored by reference, such as an object or array.
- **Template literal**: a backtick string that supports `${}` interpolation.
