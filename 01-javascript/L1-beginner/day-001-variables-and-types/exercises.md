# Day 1 Exercises

## Exercise 1: swap
Write `swap(a, b)` that returns `[b, a]`.

## Exercise 2: describeType
Write `describeType(value)` that returns an accurate type name as a string.
It must return `"null"` for `null` and `"array"` for arrays, otherwise `typeof`.

## Exercise 3: formatPrice
Write `formatPrice(name, price, qty)` returning a string like `"3 x Coffee = $13.50"`.
Always show 2 decimal places.

Put your attempts in a scratch file first, then compare with `solutions/`.
Run the tests with `npm test`.
