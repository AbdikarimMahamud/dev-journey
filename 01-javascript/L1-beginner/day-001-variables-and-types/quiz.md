# Day 1 Quiz

1. Which keyword should you use by default?
2. What does `typeof null` return?
3. What is the result of `"5" + 3`? And `"5" - 3`?
4. Name the falsy values in JavaScript.
5. What is the difference between `||` and `??`

<details>
<summary>Answers</summary>

1. `const`
2. `"object"` (a long-standing quirk)
3. `"53"` and `2`
4. `false`, `0`, `-0`, `0n`, `""`, `null`, `undefined`, `NaN`
5. `||` falls back on any falsy value, `??` only on `null` or `undefined`.

</details>
