# dev-journey

A daily learning log covering JavaScript, Python, databases, React and Next.js.
Each day adds notes, examples, exercises, tested solutions and a quiz, and difficulty rises gradually.

## Structure
- `01-javascript/` to `05-nextjs/`: topic tracks organised by level
- `06-mini-projects/`: small apps combining several topics
- `cheatsheets/`: quick references that grow daily

## Run the tests
```bash
npm test
```
(Requires Node 18+.)
