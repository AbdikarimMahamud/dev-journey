# PHP Track

Documentation, runnable examples, exercises and tests covering PHP from first script to modern PHP 8.

## Layout
| Folder | Contents |
|---|---|
| `docs/` | 23 short guides, ordered from beginner to intermediate |
| `examples/` | 22 runnable scripts, one per concept |
| `exercises/` | Practice problems and reference solutions |
| `tests/` | A tiny dependency-free test runner |

## Requirements
PHP 8.1 or newer. Check with `php -v`.

## Run an example
```bash
php 07-php/examples/01-hello-world.php
```

## Run the tests
```bash
php 07-php/tests/run-tests.php
```

## Suggested reading order
Start at `docs/01-introduction.md` and follow the numbering. Run the matching example after each guide.
