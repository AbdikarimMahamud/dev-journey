# PHP Glossary

- **Autoloading**: loading class files automatically when first used.
- **CSRF**: an attack that tricks a logged-in user's browser into sending an unwanted request.
- **Composer**: PHP's dependency manager.
- **Dependency injection**: passing a class its dependencies instead of creating them inside.
- **Enum**: a type with a fixed set of named cases (PHP 8.1).
- **Interface**: a contract listing methods a class must implement.
- **Namespace**: a prefix that groups classes and avoids name clashes.
- **PDO**: PHP Data Objects, the database access layer.
- **PSR**: PHP Standard Recommendation published by PHP-FIG.
- **Session**: server-side storage tied to a visitor.
- **Superglobal**: built-in variable available everywhere, such as `$_GET`.
- **Trait**: a reusable group of methods mixed into classes.
- **XSS**: injecting script into a page through unescaped output.
