# Glossary: Day 1

- **Dynamic typing**: types are attached to values, not variable names.
- **Immutable**: cannot be changed after creation (`int`, `str`, `tuple`).
- **Mutable**: can be changed in place (`list`, `dict`, `set`).
- **f-string**: a string prefixed with `f` that evaluates `{expressions}`.
- **Truthy / falsy**: how a value behaves in a boolean context.
- **None**: the single value that represents "nothing".
- **Shallow copy**: copies the outer container only.
- **Deep copy**: copies nested objects too.
- **PEP 8**: the official Python style guide.
